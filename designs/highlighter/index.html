Design system

Marky "Highlighter": white paper, chunky headings and one highlighter yellow. Every screen in this site is built only from the tokens and components on this page. Each component is shown in the light and the dark theme, with all its states.

Principles

Yellow means "this matters"

Highlight is reserved for pinned notes, checked items, the active tool, H2s, link underlines and search matches. Never use it as decoration or as a plain background.

Words in front of syntax

In Write mode the Markdown characters fade to a faint grey and the text keeps its weight and size, so the note reads well even before you switch to Read.

One dark action per screen

The inverse (dark ink) pill is the main action: New note, Delete in the dialog, the selected mode. Everything else sits on the soft grey surface.

Typography

Three families, all free under the SIL Open Font License and available on Google Fonts. Bundle them as font resources in the app; don't rely on system fonts. Highlighted weights are the ones the app uses; ship only those files.

Nested lists

Indent an item with spaces under the item above it to nest it. Bullet, numbered and checklist items can nest inside each other. A child list starts where its parent's text starts: 22 under a bullet, 26 under a number, 34 under a checkbox. Child items keep the 4 gap between items. Bullets change by level: filled ink dot, then an ink ring (1.5 stroke), then a filled muted dot for level 3 and deeper. Numbers look the same at every level. From level 4 on, lists stop indenting further so text keeps enough width on a phone. Checking a parent doesn't change its children.

Content & platform

Writing rules

  • Time since edit: "Just now" (under 1 min), "4 min", "2 h", "Yesterday", "3 d", "1 w" (up to 4 weeks), then the date: "12 Aug", or "12 Aug 2025" in an earlier year.
  • Missing title: show "Untitled" in muted. Export uses "Untitled.md".
  • Previews: strip Markdown syntax, collapse line breaks, show "No text yet" for empty notes.
  • Names in messages: note titles and file names go in straight double quotes: Delete "Trip to Lisbon"?
  • Errors: say what failed and what to do next. No apologies, no "Oops".
  • Case: sentence case everywhere, including buttons and menu items.

iOS and Android

  • One design for both. Same tokens, components and layouts. Only the items below differ.
  • Back: chevron icon and edge swipe on iOS; arrow icon and system back gesture on Android.
  • Overflow icon: horizontal dots on iOS, vertical dots on Android.
  • Status bar and home indicator: system owned; draw content edge to edge and pad with the safe-area insets.
  • Keyboard: system keyboard. The formatting toolbar is attached to the top of the keyboard and moves with it.
  • Import and export: the system file picker and save dialog (Document Picker on iOS, Storage Access Framework on Android). The app doesn't draw its own.
  • Pressed state: the pressed colors above on both platforms. Android may add the default ripple on top.
