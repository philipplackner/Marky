Notes list

The home screen. Pinned notes sit on top as yellow tiles, then all other notes by last edit. From here users create, import, search and open notes. Tap a note or the search field to jump to that feature.

Main states

Empty & first launch

New users never see an empty list: the app ships with sample notes. The empty state appears only after all notes are deleted.

Import

The import button opens the system file picker for a single .md file. Users stay on the list the whole time.
