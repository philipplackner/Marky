Marky design directions

Three directions for the same app. Each one shows the notes list, a note in edit mode with the formatting toolbar, and the same note in preview, so you can compare how headings, checklists, quotes, code blocks and links render.

1. Plaintext 2. Highlighter 3. Night reading

1. Plaintext Markdown as the visual identity

Monospace titles and a single cobalt accent for every bit of Markdown syntax. In preview the ## marks don't vanish; they hang faintly in the margin, so reading and writing feel like the same document. Cool, quiet, tool-like.

2. Highlighter Friendly, bold, a bit playful

White paper, chunky grotesque headings and a highlighter yellow used only where something matters: pinned notes, checked items, the active tool, H2 marks and search hits. Syntax in edit mode fades to light grey so the words stay in front.

3. Night reading Calm, editorial, book-like

A deep ink-blue base with warm paper-coloured text and an amber accent. Note titles and the preview use a reading serif, so a formatted note feels like a page from a book. Edit mode switches to mono. Shown in dark here; the light theme would invert to warm paper with ink text.
